# Setup Guide for Local Use
1. Install Node.js for vite
2. clone the respository in your local machine.
3. Head inside the root folder of the repository and install dependencies with "npm install"
4. Start the server with "npm run dev" and click on the url which looks something like "https://localhost:1234"
